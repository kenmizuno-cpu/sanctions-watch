# 外務省 Phase 3B: 名称候補とページ証跡

## 範囲

手動取得済みの `current_un` と `current_1373` の原本PDFをローカルで解析する。
人物・団体・種別不明を分け、和文主名称・英字主名称・原文字表記・別名・弱い別名・旧称を候補として保存する。
報道発表の別添は資料ごとの形式が異なるため、この版の対象には含めない。

```bash
.venv/bin/python -m src.mofa_names
```

指定資料だけの診断は `--document-key current_un` または `current_1373`。
指定実行は出力全体を指定資料だけで再生成する。通常運用は指定なしで2資料を解析する。

## 出力

| ファイル | 内容 |
|---|---|
| data/mofa/extraction/records.csv | 資料内レコード、人物・団体・不明、現行／解除済み、原文 |
| data/mofa/extraction/names.csv | 名称候補とその根拠行、PDFページ、原本URL |
| data/mofa/extraction/issues.csv | 注記・種別不明・文字順・構造異常等のレビュー事項 |
| data/mofa/extraction/pages.jsonl | PDF全ページの抽出テキストとページURL |
| data/mofa/extraction/report.json | 文書別の件数・解析状態・自動反映停止状態 |

`source_record_id` は「文書SHA256:セクション:資料内番号」。1373号資料で番号がセクションごとにリセットされても衝突しない。
このIDは文書版の証跡IDであり、版をまたぐ人物同一性のIDではない。
`name_id` は解析器版・レコードID・名称区分・値・原文位置に紐づく。
全名称に原本SHA256、保存済み原本パス、1始まりのPDFページ、根拠原文、ページ内行番号を付ける。
複数ページの名称は `pages` に全ページを列挙し、`source_page_url` は最初のページを開く。
公式URLの原本が将来置き換わった場合は、`raw_path` とSHA256で固定版を確認する。

## 安全性

- master、社内取込、既存差分、Phase 3Aの状態・文書レビュー・確認日時を変更しない。
- 全候補は `REVIEW_REQUIRED`、`screening_eligible=false`、`applied=false`。
- `AUTO IMPORT=BLOCKED` は解析成功時も維持する。抽出成功は反映承認を意味しない。
- 解除・削除の番号は履歴レコードにのみ残し、現行名称にはしない。
- 人物・団体は生年月日・所在地・国連参照番号・公式手配書URL等の根拠で分類。根拠不足は `unknown`。
- 明示的な別名ラベルだけを対象にする。注記中の人物名を別名にしない。
- (a)/(b)等とセミコロンは括弧の外側で分割。カンマ・読点は姓名の区切りと別名列挙を区別できないため、原文のまとまりを要レビュー候補として保持。
- 生年月日等が混ざった別名は注記ごと保持し、`NAME_AMBIGUOUS` を付ける。確定した個別名称として扱わない。
- アラビア文字等はPDFの抽出順が論理的な文字順と異なる場合がある。原文字候補は `RTL_ORDER_REVIEW` を付け、原本ページの目視を要求する。機械的な逆順補正はしない。
- 原本SHA256不一致、原本取得不可、資料形式不一致、空／画像ページ、番号の飛び・重複、主名称欠落、公表件数不一致は `BLOCKED`。失敗資料の以前の名称を正常な候補として流用しない。
- 5出力は既存の `atomic_replace_many` で一括保存。通常のI/O例外に対するロールバックを利用する。電源断・SIGKILL・同時読取の完全な原子性は保証しない。

この出力は最新版資料の候補投影。履歴原本・取得イベントは既存Phase 3Aに残る。
レビューの承認操作、人物の版間同一性、差分判定、master反映、Google Sheetsへの名称レビュー表示は次段階。
